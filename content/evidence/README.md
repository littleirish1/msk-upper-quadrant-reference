# Evidence Content

This folder is reserved for reviewed evidence notes and source-linked summaries.

## What Belongs Here

- Reviewed paper summaries.
- Evidence notes linked to source metadata.
- Clinical reasoning evidence used by cases, condition pages, and teaching sessions.

## What Should Not Be Committed

- Raw copyrighted papers unless explicitly allowed.
- Private or patient-identifiable material.
- Credentials, API keys, or local machine paths.
- Unreviewed imported notes presented as final evidence.

## Review Status

Evidence material should include source metadata and a review status. Imported or generated notes are draft and unreviewed until checked by a human reviewer.

The long-term scope is whole-body physiotherapy clinical reasoning, not only upper quadrant content.
