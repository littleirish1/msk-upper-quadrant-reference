# PowerPoint Imports

This folder is reserved for future teaching-slide imports for the MSK Clinical Reasoning Lab.

## What Belongs Here

- Raw slide files placed under `raw/`.
- Extracted text, slide metadata, and source notes placed under `extracted/`.
- Source records that can later link to cases, evidence notes, and teaching sessions.

## What Should Not Be Committed

- Private or patient-identifiable material.
- Unlicensed files or files without permission for educational reuse.
- Credentials, API keys, or local machine paths.
- Reviewed learner content. Reviewed outputs should live in their appropriate content area.

## Review Status

Imported slide material is draft and unreviewed until checked by a human reviewer. Any generated case, teaching session, or evidence note should keep source metadata and `reviewStatus: "needs-review"` until approved.

The long-term scope is whole-body physiotherapy clinical reasoning, not only upper quadrant content.
