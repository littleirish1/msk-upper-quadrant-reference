# Presentations

This folder is reserved for future reviewed teaching sessions and presentation drafts.

## What Belongs Here

- Source-linked teaching session outlines.
- Reviewed presentation drafts.
- Materials linked to cases, papers, evidence notes, or PowerPoint imports.

## What Should Not Be Committed

- Private or patient-identifiable material.
- Credentials, API keys, or local machine paths.
- Unreviewed generated decks presented as final teaching material.
- Raw PowerPoint imports, which belong under `content/imports/powerpoints/raw/`.

## Review Status

Presentation material should remain draft and unreviewed until checked. Reviewed sessions should keep source metadata linking them back to imported slides, papers, cases, or manual teaching plans.

The long-term scope is whole-body physiotherapy clinical reasoning, not only upper quadrant content.
