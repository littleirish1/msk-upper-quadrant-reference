# Deterministic Seeded Patient Generator

The private generator combines an exact recipe revision, immutable Patient Truth Record hash, module revisions, rule-catalogue revision/digest, variation level, and opaque seed. Stable key ordering and UTF-8/LF output make identical inputs byte-equivalent.

The current nine recipes are private drafts and permit cosmetic aliases only. Cosmetic variation is stored outside authoritative truth. Clinical and complex variation fail closed because no approved variant modules or rules exist. Public generation also fails until the exact recipe, modules, rules, truth, evidence relationships, generated truth hash, and publication decision are approved.

Each result contains an opaque non-diagnostic instance ID, reproducibility manifest, authoritative output hash, contradiction/escalation/disclosure scans, evidence-gap count, difficulty/diversity summary, similarity warnings, and a human-review requirement. No clinical rule or patient fact is generated by randomness.
