# Legacy Guided-Case Migration

Legacy conversion is deliberately selective and fail-closed.

1. Identify the exact governed source station and exact-byte source hash.
2. Select only a station with enough material for a reviewable draft.
3. remove display names and unnecessary identifiers from derivative content;
4. map only source-supported facts into the v2 structure;
5. classify immediate, reveal-gated, internal and review-required fields;
6. record omissions, transformations, evidence gaps and source-clearance gaps;
7. validate the draft and prove it is absent from routes, search, sitemap and
   static export;
8. obtain separate clinical, evidence, source-clearance and publication
   decisions for the current revision before considering publication.

Source station identifiers stay internal. Missing content is represented as a
structured blocker and is never filled with general knowledge merely to make a
record appear complete.

The current pilots cover cervical, traumatic shoulder and wrist/hand
presentations. They were chosen for distinct learning structures and adequate
source shape. They remain private drafts and are not clinical recommendations.
