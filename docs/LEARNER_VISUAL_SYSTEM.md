# Learner visual system

## Purpose

The Version 1 learner surface presents reviewed material as an active clinical reasoning environment. The visual system is deliberately calm, structured, and explicit about governance status.

## Visual language

- Deep navy establishes the primary navigation and learning context.
- Teal identifies safe actions, active pathways, and reviewed progress.
- White and neutral surfaces keep dense reference material readable.
- Amber is reserved for the clinical disclaimer; red remains reserved for safety and red-flag meaning.
- Rounded cards group a single learning decision without implying a clinical conclusion.

## Information hierarchy

The homepage moves from action to pathway to region. The case library introduces the three supported modes before listing reviewed cases. Anatomy separates available records from future interactive systems.

## Governance states

Unreviewed 3D, movement, and one-best-answer systems have no public routes. They appear only as non-interactive roadmap panels labelled `Review required · route withheld`. This is a product state, not a disabled clinical recommendation.

## Accessibility and responsive behaviour

- A keyboard-visible skip link targets the main landmark.
- Global focus indicators use a high-contrast three-pixel teal outline.
- Controls retain a minimum 44-pixel touch target.
- Layouts collapse to single-column reading order without hiding content.
- Meaning is communicated in text as well as colour and iconography.

## Release constraint

Visual polish does not alter review status. A private asset, claim, module, question, model, or movement record becomes public only through its governed promotion workflow.
