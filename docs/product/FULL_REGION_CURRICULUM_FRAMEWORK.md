# Full-Region Curriculum Framework

The full-region plan uses `src/data/taxonomy.ts` as its only canonical region
taxonomy. It does not introduce a second route stack.

Current live regions retain their reviewed condition routes:

- cervical;
- thoracic;
- shoulder;
- elbow;
- wrist/hand.

Planned region records remain roadmap-only:

- lumbar spine;
- pelvis/SIJ;
- hip;
- knee;
- ankle/foot.

The generated curriculum report records each region's route state, condition
count, content-plan source, publication eligibility, and blockers. A planned
region cannot create:

- a condition route;
- a Search entry;
- a sitemap entry;
- a navigation link that implies live content;
- a public case or learning assessment.

New regions use the existing condition, case, Evidence Hub, Search, route, and
review systems after real source-supported content and exact-revision approvals
exist.
