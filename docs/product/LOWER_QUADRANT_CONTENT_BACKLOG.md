# Lower Quadrant And Spinal Content Backlog

This is a governed planning backlog. It does not create live clinical pages or assert that any topic is reviewed. Every item requires verified sources and clinician sign-off before public publication.

## Shared Requirements

- Proposed schema: condition page plus optional guided case, anatomy, test, and outcome-measure records.
- Source requirement: approved guideline or primary evidence appropriate to the claim, with citation verification.
- Clinical review: required for all assessment, red-flag, investigation, management, and prognosis content.
- Status: planned and not public.
