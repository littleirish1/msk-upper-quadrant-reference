# Manual review checklist

- [ ] Confirm the declared base and implementation HEAD match the commit graph.
- [ ] Apply the implementation patch independently and review every correction commit.
- [ ] Recompute every tracked-report snapshot hash against the committed source reports.
- [ ] Inspect XLSX empty, rich-text, inline-string, multi-sheet, and invalid-index fixtures.
- [ ] Confirm every eligible source-list is empty while cleared count is zero.
- [ ] Confirm restricted and quarantined IDs occur only in correctly marked informational sections.
- [ ] Confirm both proposal nodes are blocked and contain no support source IDs.
- [ ] Confirm candidate references are zero and no external verification is claimed.
- [ ] Confirm public routes, clinical bodies, and learner behavior are unchanged.
