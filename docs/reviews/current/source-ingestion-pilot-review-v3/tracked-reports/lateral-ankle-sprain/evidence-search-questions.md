# Lateral ankle sprain evidence search questions

## Questions

- Fracture-screening decision rules?
- Acute loading and support?
- Exercise and balance interventions?
- Return-to-sport criteria?
- Chronic instability and recurrence?
- Imaging and referral?
- Current patient information?

## Hierarchy

Preferred hierarchy: current clinical practice guideline; systematic review/meta-analysis; high-quality randomised trial; prognostic cohort; diagnostic-accuracy study; consensus where stronger evidence is unavailable. No external search was performed.
