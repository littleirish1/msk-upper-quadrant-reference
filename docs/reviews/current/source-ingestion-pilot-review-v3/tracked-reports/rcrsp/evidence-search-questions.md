# RCRSP evidence search questions

## Questions

- Preferred terminology and classification?
- Diagnostic value of tests and clusters?
- Imaging indications?
- Natural history and prognosis?
- Intervention comparisons?
- Surgical indications?
- Supported communication?
- Appropriate outcome measures?

## Hierarchy

Preferred hierarchy: current clinical practice guideline; systematic review/meta-analysis; high-quality randomised trial; prognostic cohort; diagnostic-accuracy study; consensus where stronger evidence is unavailable. No external search was performed.
