# UX Backlog

## Issue 1 - Reasoning boxes need model answers/check-off

Where: guided case reasoning section

Problem:
The boxes such as:

- leading hypothesis
- two supporting features
- two caution/safety features
- what would you assess next

do not clearly give an answer for each section.

Expected:
Each box should have a model answer or checklist-style feedback that can be marked off against the learner response.

Priority: medium

## Issue 2 - Reveal suggested reasoning should collapse/hide

Where: guided case reasoning section

Problem:
The "Reveal suggested reasoning" content is not behaving like a proper collapsible hidden/shown section.

Expected:
Reveal buttons should work as hidden/show controls. Suggested reasoning should not remain awkwardly open or unclear.

Priority: medium

## Issue 3 - Conversation should feel like messages, not buttons

Where: guided case conversation section

Problem:
The current conversation uses specific buttons that continue dialogue. It feels too much like button selection.

Expected:
Make the interaction feel more like a feed/response conversation where the learner asks targeted questions and receives patient-style responses. This should eventually apply across all cases.

Priority: medium
