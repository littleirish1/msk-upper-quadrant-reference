# Quarantined 3D Assets

This local/private area is reserved for 3D assets whose source, author, licence, attribution, anatomical review, or clinical review is not verified.

Quarantined assets must not be copied into `public/`, imported by `src/app/`, or included in `out/`.

No GLB files are currently present in this repository. The filenames identified by the independent review are recorded in `docs/3D_ASSET_PROVENANCE.md` and remain publicly ineligible unless verified source records are supplied.
