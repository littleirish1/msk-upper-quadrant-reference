# Agent Delegation

| Role | May do | Must not do |
|---|---|---|
| Intake | Validate metadata, checksum, restrictions | Infer rights or approve sensitive material |
| Evidence | Extract claims and limitations | Invent claims, references, or certainty |
| Citation | Compare identifiers and source text | Fill missing identifiers by guesswork |
| Drafting | Prepare a private proposal | Write directly to published content |
| QA | Run checks and identify gaps | Approve clinical correctness |
| Reviewer assistant | Assemble a focused review | Self-approve or push |

Human clinical sign-off and the repository gate remain mandatory.
