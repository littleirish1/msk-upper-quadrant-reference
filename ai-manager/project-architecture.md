\# MSK Clinical Reasoning Lab Architecture



\## Current repo status



This repo currently began as an upper quadrant MSK reference site.



Current primary content regions include:



\- Cervical

\- Thoracic

\- Shoulder

\- Elbow

\- Wrist/Hand



The repo is now evolving into an interactive MSK clinical reasoning platform.



\## Project identity



Working identity:



MSK Clinical Reasoning Lab



Purpose:



An interactive MSK reference and revision guide that combines:



\- Region and condition pages

\- Guided clinical cases

\- Evidence-linked learning

\- Red flag reasoning

\- Special tests and outcome measures

\- Future dynamic case generation

\- Future evidence update/review workflows

\- Future PowerPoint/teaching-material ingestion



\## Single source of truth



The main website repo is the source of truth.



The AI/LLM/Aider layer is a maintenance and drafting assistant only.



Generated content should be treated as draft until reviewed.



\## Current architecture



Condition pages live at:



content/\[region]/\[condition].mdx



Guided cases live at:



content/cases/\[region]/\[case-slug].mdx



Case templates live at:



content/\_TEMPLATE/cases/



AI/agent instructions live at:



ai-manager/

Do not build lower limb as a separate site.



Lower limb and spinal content should extend the same existing system:



\- Same MDX structure

\- Same case system

\- Same evidence approach

\- Same search index

\- Same layout/design language

\## Safety rule



Clinical content generated by an AI agent should be reviewed before being treated as final.



Agents may draft:



\- Cases

\- Summaries

\- Search terms

\- Evidence queue items

\- MDX structure



Agents should not automatically publish:



\- New clinical management recommendations

\- Red flag advice

\- Treatment claims

\- Evidence conclusions



without human review.
