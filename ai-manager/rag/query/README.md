# Query Scaffolding

Future local query scripts can live here.

Possible scripts:

- `query-local-index.mjs`
- `find-related-sources.mjs`
- `compare-case-to-sources.mjs`

Query results should always include traceability fields such as `sourceId`, `sourcePath`, `chunkId`, review state, and linked outputs. This folder must not become a public route or public API.
