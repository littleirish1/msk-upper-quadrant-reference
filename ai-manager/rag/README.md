# Local RAG Scaffold

This folder is reserved for future local-only retrieval, source indexing, and AI-assisted drafting tools for the MSK Clinical Reasoning Lab.

Current status:

- No live vector database.
- No embeddings.
- No API calls.
- No runtime integration.
- No public learner-site exposure.

Future tools here may index source metadata, case MDX, extracted legacy stations, PowerPoint text, paper extracts, evidence notes, and reviewed teaching material. Any generated case, evidence note, or teaching deck must remain draft or `needs-review` until checked by a human reviewer.

Do not commit private documents, API keys, environment files, sensitive source material, or unreviewed clinical outputs here. Keep this area local/back-office only.
