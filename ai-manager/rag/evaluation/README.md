# Retrieval Evaluation Scaffolding

Future retrieval evaluation scripts can live here.

Possible scripts:

- `evaluate-retrieval-coverage.mjs`
- `evaluate-citation-coverage.mjs`
- `evaluate-draft-source-support.mjs`

Evaluation should check whether retrieval results cover the right sources, cite traceable metadata, and avoid unsupported clinical claims. It should support human review rather than replace it.
